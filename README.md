Supply Chain Delivery Performance Analytics

Project Overview
Developed an interactive Power BI dashboard to analyze supply chain delivery performance, shipment modes, freight costs, and data quality.

The project focuses on identifying delivery inefficiencies, comparing transportation performance, and supporting data-driven logistics decisions.

Tools & Technologies
- Power BI Desktop
- Power Query for data cleaning and transformation
- DAX for KPI calculations and performance analysis
- Data visualization and dashboard design

Key Performance Indicators

 KPI                       Result 

 Total Delivery Records -           10,324 
 On-Time Delivery Rate -            88.51% 
 Delayed Delivery Rate -            11.49% 
 Total Freight Cost -               Approximately 68.82 million 
 Missing Shipment Mode Records -    360 
 Missing Shipment Mode Percentage - 3.49% 

Dashboard Features
- Interactive Country and Shipment Mode filters
- Delivery status distribution
- On-time delivery performance by shipment mode
- Freight cost comparison across shipment modes
- Average late delivery days analysis
- Shipment mode data quality monitoring

Key Business Insights
1. Approximately 88.51% of deliveries were on time, while 11.49% experienced delays.
2. Delivery performance varies across shipment modes, highlighting opportunities for transportation optimization.
3. Freight cost analysis identifies transportation modes contributing most to overall logistics expenditure.
4. Approximately 3.49% of records have missing shipment mode information, indicating a data quality improvement opportunity.
